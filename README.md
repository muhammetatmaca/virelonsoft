## 1. Genel Bakış

**VirelonSoft**, dijital sistemlerin mühendislik kalitesini ve hızını en üst seviyeye taşımak amacıyla kurulmuş bağımsız bir yazılım stüdyosudur. Kurucusu ve baş mimarı, 50'den fazla üretim seviyesi mobil uygulama geliştirmiş olan **Muhammet Atmaca**'dır.

Stüdyo; mobil uygulama geliştirme, kurumsal ERP entegrasyonu, gerçek zamanlı veri hatları ve yapay zeka arama motorları için optimize edilmiş teknik web platformları üretir.

---

## 2. Temel Yetkinlikler & Hizmet Alanları

### 2.1. Yüksek Performanslı Mobil Uygulamalar (iOS & Android)
* **Teknolojiler:** React Native, Expo, SwiftUI, Kotlin, Reanimated, RevenueCat, OneSignal
* **Mimari:** Clean Architecture, Offline-First veri modeli, 60 FPS akıcı native köprüleme.
* **Mağaza Onay Süreci:** Apple App Store ve Google Play Store yönergelerine %100 tam uyum ve canlıya alma garantisi.

### 2.2. Logo ERP Entegre B2B Bayi Portalları
* **Entegrasyon:** Logo Tiger 3, Logo Go 3 ve kurumsal ERP veritabanları (MSSQL / REST API).
* **Yetkinlikler:** Çift yönlü anlık cari bakiye, dinamik iskonto hesaplama, gerçek zamanlı stok kontrolü, bayi sipariş altyapısı ve e-fatura entegrasyonu.

### 2.3. Dağıtık Mikroservisler & Bulut Mimarisi
* **Teknolojiler:** ASP.NET Core, Node.js, TypeScript, PostgreSQL, Redis, Docker, Cloudflare Workers & Pages.
* **Güvenlik:** Zero-Trust mimarisi, RFC 9116 güvenlik protokolleri, JWT rotasyonu ve RBAC yetkilendirme.

### 2.4. Teknik SEO & Yapay Zeka Arama Motoru Optimizasyonu (GEO / LLMO)
* **Standartlar:** 100/100 Google Core Web Vitals, JSON-LD Schema.org (`Organization`, `WebSite`, `ProfessionalService`, `FAQPage`, `BreadcrumbList`).
* **AI/LLM Erişimi:** ChatGPT, Perplexity, Claude ve Gemini modelleri için optimize edilmiş `llms.txt`, `llms-full.txt`, XML sitemap ve IndexNow protokolleri.

## 3. Öne Çıkan Projeler

* **Logo ERP Entegre B2B Portalı:** Bayilerin mobil ve masaüstünden 7/24 anlık stok ve cari ekstresiyle sipariş vermesini sağlayan, Logo Tiger 3 çift yönlü SQL senkronizasyonlu kurumsal platform.
* **Teleflow AI Akıllı Teleprompter:** Konuşma hızına duyarlı ses takipli ve 60 FPS floating widget modlu profesyonel React Native içerik üretici uygulaması.
* **WebGL Shaders & Donanım Hızlandırma:** Özel WebGL fragment shader'ları (`TopoField`, `TidalStipple`) ve ekran dışı pausing mekanizması ile 120 FPS akıcı render deneyimi.

## 5. Yerel Geliştirme ve Çalıştırma

### Gereksinimler
* Node.js 18+ (Node 20 veya 22 önerilir)
* npm veya pnpm

### Kurulum Adımları

1. Depoyu klonlayın:
```bash
git clone https://github.com/muhammetatmaca/virelonsoft.git
cd virelonsoft
```

2. Bağımlılıkları yükleyin:
```bash
npm install
```

3. Geliştirici sunucusunu başlatın:
```bash
npm run dev
```

4. Üretim derlemesi (Production Build):
```bash
npm run build
```

## 6. SEO & İndeksleme Betikleri

Projede otomatik arama motoru sinyalleri için hazır NPM komutları yer almaktadır:

* `npm run seo:indexnow` — Tüm site haritasını IndexNow (Bing, Yandex, Seznam) API'lerine iletir.
* `npm run seo:google` — Google Indexing API üzerinden sayfaları anında Googlebot tarama kuyruğuna sokar.
* `npm run seo:wayback` — İnternet Arşivi'ne (Wayback Machine) kalıcı sürüm yedekleri gönderir.
* `npm run seo:all` — Tüm arama motoru indeksleme süreçlerini sırayla çalıştırır.
