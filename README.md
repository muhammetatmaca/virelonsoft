## 1. Şirket Profili & Genel Bakış

**VirelonSoft**, orta ve büyük ölçekli şirketlerin operasyonel yüklerini otomatize eden, veri akışlarını merkezileştiren ve modern dijital altyapılarını sıfırdan inşa eden bir **kurumsal yazılım şirketidir**. 

Şirketimiz; ERP entegrasyonları, B2B ticaret sistemleri, karmaşık veri tabanı mimarileri, yüksek trafikli web platformları ve entegre mobil sistemler geliştirmektedir. Kurucusu ve baş mimarı **Muhammet Atmaca**'dır.

---

## 2. Mühendislik & Hizmet Alanlarımız

### 2.1. Özel Kurumsal Yazılım Geliştirme (Custom Enterprise Software)
* Şirket içi iş süreçleri, sipariş/stok takibi, bayi ağı yönetimi ve operasyonel otomasyonlar için terzi işi yazılım sistemleri.
* Dağıtık mikroservis mimarisi (ASP.NET Core, Node.js, Go) ve ACID uyumlu güvenilir veri tabanları (PostgreSQL, MSSQL).

### 2.2. ERP Entegrasyonları & B2B Bayi Portalları
* **Logo ERP (Tiger 3 / Go 3 / Netsis):** Çift yönlü, gerçek zamanlı cari bakiye, fatura, sipariş ve stok senkronizasyonu.
* Dağıtıcı firmaların yüzlerce bayisi için kesintisiz sipariş alma, iskonto mekanizmaları ve ödeme altyapıları.

### 2.3. Yüksek Performanslı Web Sistemleri & SaaS Platformları
* React 19, TypeScript ve Next.js tabanlı, milisaniyelik yanıt sürelerine sahip kurumsal arayüzler.
* Core Web Vitals 100/100, teknik SEO ve arama motorları için optimize edilmiş dijital vitrinler.

### 2.4. Entegre Mobil Uygulama Sistemleri (iOS & Android)
* Kurumsal sistemlere doğrudan bağlı çalışan saha satış, sipariş toplama, müşteri sadakat ve iş takip uygulamaları (React Native, SwiftUI, Kotlin).
* Çevrimdışı (offline-first) çalışma kabiliyeti ve merkezi bulut senkronizasyonu.

### 2.5. Bulut Altyapısı, DevOps & Güvenlik
* Docker, Kubernetes, Cloudflare Pages/Workers, Redis önbellekleme ve Zero-Trust ağ güvenliği.
* RFC 9116 güvenlik standartları, rol bazlı erişim kontrolü (RBAC) ve otomatik CI/CD hatları.

## 3. Canlı Kurumsal Referanslar & Projeler

* **Logo ERP Entegre B2B Bayi Portalı:** Yüzlerce bayinin doğrudan distribütör stoklarına bağlanıp cari hareketlerini inceleyerek anında sipariş oluşturduğu yüksek erişilebilirlikli kurumsal yazılım.
* **Teleflow AI Akıllı Sistem:** Konuşma analitiği ve gerçek zamanlı kaydırma motoruna sahip profesyonel içerik üretim sistemi.
* **Kurumsal Web Platformları & Shaders:** WebGL donanım hızlandırmalı modern kurumsal arayüzler ve mikroservis entegrasyonları.

## 5. Kurulum ve Geliştirme

```bash
# Depoyu klonlayın
git clone https://github.com/muhammetatmaca/virelonsoft.git
cd virelonsoft

# Bağımlılıkları yükleyin
npm install

# Geliştirici sunucusunu başlatın
npm run dev

# Üretim derlemesi
npm run build
```

---

## 6. SEO & İndeksleme Araçları

* `npm run seo:indexnow` — Bing, Yandex ve arama motorlarına site haritasını anında bildirir.
* `npm run seo:google` — Google Indexing API ile tüm kurumsal sayfaları tarama kuyruğuna sokar.
* `npm run seo:wayback` — İnternet Arşivi'ne kalıcı şirket sürüm kayıtlarını gönderir.
* `npm run seo:all` — Tüm arama motoru indeksleme süreçlerini tek seferde yürütür.
